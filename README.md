# 🔐 Gerador de Senhas — JavaScript

Gerador de senhas aleatórias e seguras desenvolvido com **HTML, CSS e JavaScript puro**.

---

## ✨ Funcionalidades

- Controle do **comprimento** da senha (slider)
- Opções de inclusão: **letras minúsculas**, **maiúsculas**, **números** e **símbolos**
- Geração instantânea com clique no botão
- Interface moderna e responsiva

## 🚀 Como executar

Abra o arquivo `index.html` no navegador.
